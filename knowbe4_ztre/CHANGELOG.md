# 2.0.0 (Requires minimum Cloud Exchange version 6.1.0)
## Added
- Added new fields to the Users entity.
- Added support for 'Add User to Group', 'Remove User from Group', 'Enroll in Training' and 'Update Custom Field' actions.
- Added support for pulling additional details which includes 'Pulling Past Due training Details', 'Password IQ detections' and 'Security Coach risk scores' from KnowBe4.
- Added a 'Custom Region URL' option in the configuration parameter where user can provide custom KnowBe4 Base URL.

## Updated
- Updated the older 'Reporting API' with the newer 'GraphQL API' for pulling data and performing the plugin actions.
